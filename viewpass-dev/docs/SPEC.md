# 製品仕様 v0.1（開発用）

## 価値・対象
ワンステップで制作中の視点からパスを作りたい3D制作者、イラスト・コンポジット、AIの入力画像、研究用の補助データ。Blender標準のZ/Mist/AOV、カメラ・コンポジタ自動設定型アドオンとの差は「既存シーンを変更しない現在視点」「正確に整列した複数パス」「手順と時間の削減」。速度は測定前に保証しない。

## MVP
- Depth：カメラ空間の -Z（視線方向距離、ユークリッド距離ではない）をBlender単位で float32。背景は NaN。正規化の既定範囲は前景の min/max、同値時は明示的な定数値、背景値を独立設定。固定範囲も対応し、near=far/逆転/空シーン/非有限値を扱う。Near-white/Far-white の切替。raw EXR と表示PNGの区別。
- Normal：カメラ空間の符号付き単位法線（+X右、+Y上、+Z視点側）、面向きは元の幾何に従う。既定は幾何/スムーズのどちらかを明示（テストは平面）。非一様スケールは逆転置。表示用RGBは n*0.5+0.5、背景は別マスク。色管理による値変化禁止。
- Object ID：背景0、前景の正整数。パス内・同一capture内で一貫するIDと対応表。インスタンスは元オブジェクト単位/個別を明示（最初は元オブジェクト単位でも可）。数値IDをプレビュー色に置換しない。整数をPNG等に可逆符号化する場合は方式/上限を文書化、超過時エラー。補間・アンチエイリアス禁止。
- Mask：前景=1 / 背景=0。全可視、選択のみは追加候補。前景判定は深度と同一。MVPは可視メッシュ・不透明扱い・最前面。透過/髪/カーブ/ボリューム、マテリアルの実シェーディングは対象外または明示した限定対応。評価済みメッシュ・モディファイア・インスタンスを扱う。ローカルビュー/非表示/コレクション除外を尊重。未対応の可視要素は警告。
- カメラ不要。透視・正投影・カメラビューを試験。UIの投影は window_matrix 等の正しい行列を使用し、perspective_matrix（通常 view-projection）をさらにviewで乗じない。GPUバックエンドのclip-space規約を検証。解像度変更時はアスペクト方針（初期は縦横比ロック）を明記。
- 画像の行順はコアで top-left、書き出し時にBlender画像の座標系と整合。全パス同じピクセル中心を採用。MVPではMSAAなし。画素の正確さ優先。

## UI
```
ViewPass
  Passes [x] Depth [x] Normal [ ] Object ID [ ] Mask
  Resolution: Viewport / Custom (lock aspect)
  Depth: Auto / Fixed   Near ___ Far ___  Invert [ ]
  Preview [Depth v] [Refresh]
  Output directory / base name / format per pass
  [Export Selected]
  Status: last capture, resolution, duration, warnings
```
非破壊：scene/camera/selection/mode/frame/material/compositor/render settings を変更しない。永続画像データブロックの無断作成は禁止、プレビュー用は所有管理し終了時破棄。GPU状態・ハンドラー・一時メッシュ・オフスクリーンの解放を成功/失敗両方で確認。

## 出力契約
`<stem>_depth.png`, `_depth.exr`, `_normal.png`, `_id.png`, `_mask.png`, `_meta.json` 等、明示選択のみ。バッチの衝突を事前検査、勝手に上書きしない。部分失敗はファイルごとに報告し、成功扱いしない。可能なら一時ファイル→原子的置換、同一ファイルシステムで。ユーザー指定パス外への書込禁止。metaには版、パス、行列、投影、解像度、深度単位/範囲/方向、ID対応表、警告、フレーム。不要な絶対パスや個人情報は含めない。

## 拡張（MVPのゲート通過後）
Line Art（深度/法線エッジは輪郭線近似と明記）、AO（スクリーンスペース近似なら明記）、RGB、world normal、pose、連番、画像クリップボード、ControlNet/ComfyUI向けローカルプリセット、選択マスク。外部サービス通信は別設計。通常レンダリングに匹敵するAOや透明・屈折表現を約束しない。

## リリースゲート
4.5 LTSと実際に試した5.xごとに、GPU backend/OS/版を記録。未試験プラットフォームは未検証。ファイル再読込、非破壊性、パッケージインストール、手動UI QA、競合比較を通す。速度目標は性能測定後に設定（暫定：1080p/単純シーンで対話操作を妨げない、時間内訳を測定）。
