# 手動検証表

各項目に PASS / FAIL / NOT TESTED、環境、再現手順、証拠画像/ログを記録。自作シーンを使う。

| ID | 操作 | 期待 |
|---|---|---|
| U01 | カメラのないシーンで透視/正投影を切替・出力 | 同じ視点・寸法、カメラは増えない |
| U02 | 2つの3D Viewを異なる角度で開く | 操作元のビューから出力 |
| U03 | ファイルダイアログを開いてから保存/キャンセル | 視点保持・キャンセルでファイルなし |
| U04 | Local View / hidden / collection exclusion | 対象外は出力されない |
| U05 | modifier/instance/non-uniform scale | 評価後形状・法線・ID一致 |
| U06 | Near/Farの反転、固定範囲、空シーン | プレビューと保存が仕様一致、例外なし |
| U07 | 1080p、縦長、正方形、極端サイズ | 投影方針一致、過大サイズは安全に拒否 |
| U08 | 同名ファイル、読取専用フォルダ、unicode | 上書き確認/明示エラー、正常ファイル保持 |
| U09 | プレビュー更新中にビュー閉鎖/ファイル読込/無効化 | リソース・タイマー・ハンドラ解放 |
| U10 | 20回連続capture、キャンセル、故障注入後再試行 | 状態復元、異常終了なし、リーク傾向を記録 |
| U11 | PNG/EXRを外部/Blenderで再読込 | 精度・色管理・上下・ID一致 |
| U12 | Extension ZIPをクリーンな設定でインストール | 有効化・実行・無効化・再有効化成功 |
| U13 | シーン変更前後比較（カメラ、マテリアル、ノード、選択、フレーム） | 変化なし |
| U14 | Edit Mode、カメラビュー、複数ウィンドウ | 対応範囲なら正常、未対応なら安全に明示 |
