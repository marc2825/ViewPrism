# ViewPrism brand assets

The current view (viewfinder frame + white beam) passes through a prism and splits into the four
passes: **depth** (white → grey, near = white), **normal** (blue-violet, normal-map colours), **object
ID** (coloured segments) and **mask** (mint).

| File | Use |
|---|---|
| `viewprism-icon.svg` | master app icon (512 × 512, with background) |
| `viewprism-icon-small.svg` | simplified icon for ≤ 64 px (no frame or inner light) |
| `viewprism-icon-{512,256,128}.png` | rendered from `viewprism-icon.svg` |
| `viewprism-icon-{64,32}.png` | rendered from `viewprism-icon-small.svg` |
| `viewprism-wordmark-dark.svg/.png` | icon + name for **dark** backgrounds |
| `viewprism-wordmark-light.svg/.png` | icon + name for **light** backgrounds |

Palette: background `#2a3246 → #141823`; ink `#eef2f9`; depth `#ffffff → #6b7488`; normal
`#7d9bff → #b48cff`; ID `#ff8f70`, `#ffd166`, `#5fd3c6`; mask `#7ce6b0`.

All files are generated by `python tools/make_logo.py`; edit the script, not the files. PNGs are
rendered from the SVGs with a headless Edge/Chrome, so they match exactly. The wordmark SVGs use live
text (Segoe UI → Inter → Helvetica → Arial); use the PNGs where exact typography matters.
